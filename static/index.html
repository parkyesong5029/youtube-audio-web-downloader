아이폰(iOS Safari) 저장 및 홈 화면 추가 팁

  1. 파일 앱 저장: 변환 완료 후 파일 앱에 저장을 누르면 Safari에서 다운로드되어 아이폰 파일 앱 → 다운로드 폴더에 저장됩니다.
  2. USB 외장 메모리 복사: 아이폰에 USB-C / 라이트닝 USB를 꽂은 뒤, 완료 창에서 공유 시트 → 파일에 저장 → USB 드라이브를 선택하면 바로 복사됩니다.
  3. 앱처럼 사용하기: Safari 하단 공유 버튼(□↑) → 홈 화면에 추가를 누르면 앱 아이콘으로 바로 실행할 수 있습니다.
